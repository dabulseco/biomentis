LAMP Primer Design Workflow for Streptococcus pyogenes Species-Specific Detection

Overview

This workflow guides you through designing Loop-Mediated Isothermal Amplification (LAMP) primers that specifically detect Streptococcus pyogenes (Group A Streptococcus, GAS) while excluding other Streptococcus species (e.g., S. agalactiae, S. pneumoniae, S. mutans, S. sanguinis, S. salivarius, S. dysgalactiae).

Step 1: Select a Species-Specific Gene Target

Choose one of the following validated S. pyogenes-specific genetic markers:

Gene Protein/Function Specificity Notes
speB Streptococcal pyrogenic exotoxin B (streptopain) Highly specific to S. pyogenes Most widely used target; UniProt: P0C0J0
spy1258 Hypothetical protein, S. pyogenes-specific Highly specific Validated in multiple LAMP studies
slo Streptolysin O Present in GAS and some Group C/G streptococci Use with caution; verify specificity
sdaB Streptodornase B S. pyogenes-specific Alternative target
sof Serum opacity factor Specific to certain S. pyogenes serotypes May miss some strains

Recommendation: Use speB as the primary target. It is the most extensively validated marker for S. pyogenes detection and is absent from other streptococcal species.

Step 2: Obtain the Target Gene Sequence

2.1 Retrieve the speB gene sequence

Use NCBI to obtain the full speB coding sequence from a reference S. pyogenes strain (e.g., M1 GAS strain SF370, NCBI Reference Sequence: NC_002737.2):

from biomni.tool.database import query_uniprot

# Get speB protein info and cross-reference to nucleotide
result = query_uniprot(prompt="Streptococcus pyogenes serotype M1 speB gene nucleotide sequence")

Key NCBI Accessions for speB:
- Nucleotide: NC_002737.2 (region: 1069608–1070804, complement)
- Protein: WP_010922142.1

2.2 Verify specificity by BLAST

Before designing primers, BLAST the speB gene against the NCBI nr/nt database to confirm it does NOT align to other Streptococcus species:

from biomni.tool.database import blast_sequence

# BLAST the speB sequence
result = blast_sequence(
    sequence=">speB_S_pyogenes\nATG...",  # full speB sequence
    database="core_nt",
    program="blastn"
)

Expected result: speB should only match S. pyogenes strains, with no significant hits to S. agalactiae, S. pneumoniae, S. mutans, S. dysgalactiae, or other streptococci.

Step 3: Design LAMP Primers Using PrimerExplorer

3.1 Use PrimerExplorer (Recommended)

PrimerExplorer V5 (https://primerexplorer.jp) is the gold-standard tool for LAMP primer design.

Input:
- Paste the speB gene sequence (FASTA format)
- Select "LAMP primer design" mode

Design Parameters:
| Parameter | Recommended Setting |
|-----------|-------------------|
| Primer length (F3/B3) | 18–22 bp |
| Primer length (FIP/BIP) | 38–44 bp (F1c/B1c: 18–22 bp + F2/B2: 18–22 bp) |
| Loop primer length | 18–22 bp |
| GC content | 40–60% |
| Tm of F1c/B1c | 64–66°C |
| Tm of F2/B2, F3/B3 | 59–61°C |
| Tm of LoopF/LoopB | 64–66°C |
| Amplicon size | 120–200 bp (optimal for LAMP) |
| dG (3' end) | ≤ -4 kcal/mol |
| dG (5' end of F1c/B1c) | ≤ -4 kcal/mol |

3.2 Alternative: NEB LAMP Primer Design Tool

If PrimerExplorer is unavailable, use the NEB LAMP Primer Design Tool (https://lamp.neb.com).

3.3 Manual Design Guidelines (if tools are unavailable)

LAMP requires 4–6 primers targeting 6–8 distinct regions:

F3 →  F2 →  F1 →  [TARGET REGION]  ← B1c ← B2c ← B3c
     ← F1c ← F2c                    B1 →  B2 →  B3 →

Primer structure:
- F3: Forward outer primer (binds F3c region)
- B3: Backward outer primer (binds B3 region)
- FIP: Forward inner primer = F1c (complement of F1) + F2 (binds F2c)
- BIP: Backward inner primer = B1c (complement of B1) + B2 (binds B2)
- LoopF (optional): Binds between F1 and F2 (accelerates reaction)
- LoopB (optional): Binds between B1 and B2 (accelerates reaction)

Distance guidelines:
- F2 to B2: 120–180 bp (amplicon)
- F2 to F1: 40–60 bp
- B2 to B1: 40–60 bp
- F3 to F2: 0–20 bp
- B3 to B2: 0–20 bp

Step 4: Validate Primer Specificity In Silico

4.1 BLAST each primer

BLAST each individual primer against the NCBI database to ensure no cross-reactivity:

from biomni.tool.database import blast_sequence

primers = {
    "F3": "ATCGATCGATCGATCGATCG",
    "B3": "GCTAGCTAGCTAGCTAGCTA",
    "FIP": "F1c+F2_sequence",
    "BIP": "B1c+B2_sequence",
    "LoopF": "loop_forward_sequence",
    "LoopB": "loop_backward_sequence"
}

for name, seq in primers.items():
    result = blast_sequence(sequence=seq, database="core_nt", program="blastn")
    print(f"{name}: {result}")

Acceptance criteria: Each primer should only match S. pyogenes genomes.

4.2 Check against common Streptococcus species

Specifically verify no matches to:
- Streptococcus agalactiae (Group B)
- Streptococcus pneumoniae
- Streptococcus mutans
- Streptococcus salivarius
- Streptococcus sanguinis
- Streptococcus dysgalactiae (Group C/G)
- Streptococcus anginosus group
- Streptococcus mitis
- Streptococcus oralis

4.3 Check primer-dimers and hairpins

Use tools like OligoAnalyzer (IDT) or mfold to check for:
- Self-dimers (ΔG > -9 kcal/mol acceptable)
- Cross-dimers between primer pairs
- Hairpin structures (ΔG > -3 kcal/mol acceptable)

Step 5: Order Primers

Order specifications:
- F3, B3, LoopF, LoopB: Standard desalting purification
- FIP, BIP: HPLC purification recommended (longer oligos, critical for LAMP)

Typical LAMP primer concentrations (25 μL reaction):
| Primer | Final Concentration |
|--------|-------------------|
| FIP | 1.6 μM |
| BIP | 1.6 μM |
| F3 | 0.2 μM |
| B3 | 0.2 μM |
| LoopF | 0.4 μM |
| LoopB | 0.4 μM |

Step 6: Experimental Validation

6.1 Initial LAMP reaction setup

Reaction mix (25 μL):
| Component | Volume | Final Concentration |
|-----------|--------|-------------------|
| WarmStart LAMP 2× Master Mix (NEB #E1700) | 12.5 μL | 1× |
| 10× Primer Mix (FIP/BIP: 16 μM each; F3/B3: 2 μM each; LoopF/B: 4 μM each) | 2.5 μL | See above |
| Fluorescent dye (SYTO 9, 50 μM stock) | 0.5 μL | 1× |
| Template DNA | 2 μL | 10 pg – 100 ng |
| Nuclease-free water | to 25 μL | — |

6.2 Specificity testing

Test against a panel of genomic DNA from:
1. Positive control: S. pyogenes (multiple emm types if possible)
2. Negative controls:
- S. agalactiae
- S. pneumoniae
- S. mutans
- S. salivarius
- S. dysgalactiae
- S. anginosus
- S. mitis
- S. sanguinis
- Human genomic DNA
- No-template control (NTC)

6.3 Sensitivity testing

  • Test 10-fold serial dilutions of S. pyogenes genomic DNA (100 ng → 1 fg)
  • Determine limit of detection (LoD)
  • Typical LAMP LoD: 10–100 genome copies per reaction

6.4 Reaction conditions

Parameter Setting
Temperature 65°C (standard; optimize 60–68°C)
Time 30–60 minutes
Detection Real-time fluorescence (SYTO 9, SYBR Green) or colorimetric (pH indicator)

Step 7: Troubleshooting

Problem Possible Cause Solution
No amplification Primer design issue Redesign with PrimerExplorer
Non-specific amplification in other Streptococcus spp. Insufficient specificity of target gene Switch to speB or spy1258
Late amplification (>40 min) Suboptimal primer concentrations Titrate FIP/BIP (0.8–2.4 μM)
Primer-dimers High primer concentrations Reduce primer concentrations; add DMSO (3%)
False positives in NTC Contamination Use separate areas for setup; use dUTP/UDG system
